# ⏱️ Epoch Time Converter

A simple and responsive web application that converts any selected date and time into a Unix Epoch timestamp (seconds).

## ✨ Features

- Convert any date and time into Unix Epoch seconds.
- Simple and user-friendly interface.
- Responsive design for mobile, tablet, and desktop.
- Instant timestamp calculation.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## 📖 How It Works

1. Select your desired date and time.
2. Click the **📋Submit** button.
3. The application converts the selected date and time into a JavaScript Date object.
4. The timestamp is calculated in milliseconds and converted into seconds.
5. Your Unix Epoch timestamp is displayed.

## 🌍 Timezone Information

**Note:** The timestamp is calculated based on your browser's local timezone.

Users in different time zones may receive different Epoch values for the same displayed date and time.
